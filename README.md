# Numpy
NumPy Learning Notes and Practice

A hands-on repository for learning NumPy, the core Python library for numerical computing. It covers concepts from basics to practical use, with small examples you can run and modify.

Why NumPy?

Python lists are flexible but slow for large numerical work. NumPy arrays store data of one type in contiguous memory and run operations in optimized C code. This makes them much faster and the foundation of libraries like Pandas, SciPy, scikit-learn and PyTorch.

Real-world example: if a shop wants to apply an 18% tax to 1 million product prices, a NumPy array does it in one line (prices * 1.18) instead of writing a loop.

Topics Covered
Creating arrays (array, zeros, ones, arange, linspace)
Array attributes (shape, dtype, ndim, size)
Indexing and slicing
Boolean masking and filtering
Reshaping and flattening
Broadcasting
Mathematical and statistical operations (sum, mean, std, max, min)
